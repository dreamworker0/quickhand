# 손빠르미 마스코트

손빠르미는 둥근 키캡 모양의 몸체와 민첩한 작은 손을 가진 업무 도우미입니다. 키보드를 닮은 단순한 실루엣과 부드러운 미소로 단축키를 처음 배우는 사람에게 편안하게 다가갑니다. 청록색과 짙은 남색은 차분함과 신뢰감을 전하고, 아이보리색 손은 인사와 안내 동작을 또렷하게 보여 줍니다. 과장된 표정 대신 따뜻한 손짓으로 사용자의 배움과 성취를 응원합니다.

## 색상 팔레트

- 청록색 `#2A9D8F`: 키캡 얼굴과 축하 포인트의 기준색
- 짙은 남색 `#173F4F`: 테두리, 표정, 팔과 다리의 기준색
- 아이보리색 `#FFF9ED`: 손과 안내용 키캡의 중립색

위 코드는 디자인 기준색이며, 생성된 PNG의 가장자리와 표면에는 미세한 색상 차이가 있습니다. 네 이미지 모두 투명 배경이며 이미지 안에 문자는 없습니다.

## 이미지

- `main.png`: 한 손을 들어 반갑게 인사하는 전신 기본 포즈.
- `icon.png`: 손발을 생략하고 얼굴과 굵은 실루엣을 강조한 정사각형 앱 아이콘 원본으로, 16·32·48·128px 축소용.
- `hint.png`: 글자 없는 키캡을 받쳐 들고 다른 손으로 가리키는 단축키 안내 포즈.
- `cheer.png`: 두 손을 들고 작은 반짝임과 함께 학습 성공이나 레벨 상승을 축하하는 포즈.

## 제작 정보

내장 이미지 생성 도구로 기본 포즈를 생성하고, 해당 이미지를 캐릭터 참조로 사용해 나머지 세 이미지를 제작했습니다.
공통 프롬프트: 둥근 청록색 키캡 몸체, 굵은 남색 테두리, 타원형 눈과 작은 미소, 아이보리색 손, 차분하고 친근한 업무 도우미, 단순한 플랫 벡터 스타일, 투명 배경, 문자 없음.
개별 프롬프트: 기본형은 전신으로 손을 흔들기, 아이콘은 얼굴만 크게 배치하기, 안내형은 빈 키캡을 가리키기, 축하형은 두 팔을 들고 청록색 반짝임 두 개를 배치하기.
