# 손빠르미 마스코트

손빠르미는 둥근 키캡 모양의 몸체와 민첩한 작은 손을 가진 업무 도우미입니다. 키보드를 닮은 단순한 실루엣과 부드러운 미소로 단축키를 처음 배우는 사람에게 편안하게 다가갑니다. 청록색과 짙은 남색은 차분함과 신뢰감을 전하고, 아이보리색 손은 인사와 안내 동작을 또렷하게 보여 줍니다. 과장된 표정 대신 따뜻한 손짓으로 사용자의 배움과 성취를 응원합니다.

## 색상 팔레트

- 청록색 `#2A9D8F`: 키캡 얼굴과 축하 포인트의 기준색
- 짙은 남색 `#173F4F`: 테두리, 표정, 팔과 다리의 기준색
- 아이보리색 `#FFF9ED`: 손과 안내용 키캡의 중립색

위 코드는 디자인 기준색이며, 생성된 PNG의 가장자리와 표면에는 미세한 색상 차이가 있습니다. SVG는 정확한 기준색과 단색 채움만 사용합니다. 모든 이미지는 투명 배경이며 이미지 안에 문자는 없습니다.

## 빠른 손동작 표현

손빠르미의 민첩함은 다음 두 가지 장치로만 표현합니다.

- **손 잔상**: 움직이는 손 뒤에 아이보리색과 청록색의 흐린 손 모양 두 겹을 겹칩니다. 현재 손은 선명하게, 뒤쪽 잔상은 옅게 표현하여 빠르게 움직인 경로가 보이도록 합니다.
- **짧은 속도선**: 손 주변에 남색 또는 청록색의 짧고 정돈된 선을 소량 배치합니다. 얼굴과 안내 대상의 가독성을 유지하고 차분한 업무 도구의 인상을 지킵니다.

기존 키캡 몸체, 굵은 테두리와 팔다리, 타원형 눈, 작은 미소를 유지합니다. 새로운 장식이나 소품은 추가하지 않으며, 축하 포즈에는 기존 청록색 반짝임 두 개를 유지합니다.

## 이미지

- `main.png`: 한 손을 흔들어 인사하는 전신 기본 포즈. 흔드는 손에 잔상 두 겹과 짧은 속도선 세 개를 적용합니다.
- `hint.png`: 글자 없는 아이보리색 키캡을 받쳐 들고 다른 손으로 가리키는 안내 포즈. 가리키는 손 뒤의 잔상 두 겹과 수평 속도선이 손을 빠르게 옮긴 순간을 보여 줍니다.
- `cheer.png`: 두 손을 올려 성취를 축하하는 포즈. 양손 각각의 잔상 두 겹, 짧은 속도선, 기존 청록색 반짝임 두 개를 사용합니다.
- `praise.svg`: 단축키를 잘 썼을 때 뜨는 칭찬 카드용 포즈. 두 팔을 번쩍 들고, 웃느라 감은 눈과 크게 벌린 입, 발그레한 볼, 금색·청록색 반짝임으로 기쁨을 크게 표현합니다. 다른 포즈보다 표정을 과장한 유일한 그림으로, 힌트 카드와 한눈에 구별되게 합니다. SVG 코드로 직접 작성했고 `extension/tools/build_assets.py`가 192px PNG로 만듭니다.
- `icon.svg`: **툴바 아이콘의 원본**. `viewBox="0 0 128 128"`로 직접 작성한 SVG이며, 16·32·48·128px 크기로 렌더링합니다. 굵은 남색 테두리의 둥근 키캡 얼굴과 왼쪽 속도선 세 개로 작은 크기에서도 민첩함을 나타냅니다. 정확한 기준색의 단색 채움만 사용하며 그라디언트, 필터, 문자는 없습니다.
- `icon.png`: 기존 래스터 아이콘 보관본. 이번 수정에서는 변경하지 않았으며, 새 툴바 아이콘은 `icon.svg`를 기준으로 사용합니다.
- `v1/`: 수정 전 원본 보관 폴더. 이번 수정에서 변경하지 않습니다.

## 제작 정보

세 PNG는 내장 이미지 생성 도구에 `v1/`의 해당 포즈를 각각 참조 이미지로 제공하여 수정했습니다. `icon.svg`는 이미지 생성 없이 SVG 코드로 직접 작성했습니다.

공통 프롬프트: 기존 캐릭터의 형태와 비율, 청록색 `#2A9D8F` 키캡 얼굴, 남색 `#173F4F` 테두리와 팔다리, 아이보리색 `#FFF9ED` 손, 타원형 눈과 작은 미소를 유지. 플랫 벡터 스타일, 투명 배경, 문자 없음. 움직이는 손마다 서로 겹치는 흐린 아이보리·청록 손 잔상 두 겹과 최소한의 짧은 남색·청록 속도선만 추가. 새로운 소품이나 장식 없음.

포즈별 프롬프트: 기본형은 인사하는 한 손의 위쪽 뒤로 잔상 두 겹과 짧은 속도선 세 개. 안내형은 빈 아이보리 키캡을 든 손은 그대로 두고 가리키는 손의 왼쪽 뒤로 잔상 두 겹과 수평 속도선 세 개. 축하형은 양손 각각 아래쪽 뒤로 잔상 두 겹과 양옆 속도선 두 개씩을 추가하고 기존 청록색 반짝임 두 개 유지.
