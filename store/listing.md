## 개인정보 보호 관행 (Privacy practices)

**단일 목적**:

```
사용자가 유튜브, Gmail, 구글 캘린더·드라이브·문서·시트·슬라이드에서 마우스로 한 동작에 키보드 단축키가 있으면 그 단축키를 화면에 알려 주어, 일하면서 단축키를 익히도록 돕습니다.
```

**권한별 사용 이유**:

- `storage`
  ```
  알림 설정(알림 강도, 사이트별 켜고 끄기)과 단축키 학습 기록(동작 이름, 마우스/단축키 여부, 횟수, 날짜, 최근 동작 10개의 결과)을 사용자 기기에 저장합니다. 설정만 크롬 동기화로 사용자의 다른 기기와 맞춰지며, 기록은 외부로 보내지 않습니다.
  ```
- `scripting`
  ```
  설치하거나 업데이트한 직후, 이미 열려 있던 지원 사이트 탭에 확장 프로그램의 콘텐츠 스크립트를 넣어 새로고침하지 않아도 바로 작동하게 합니다. 패키지에 포함된 파일만 넣으며, 다른 사이트에는 넣지 않습니다.
  ```
- 호스트 권한 (`www.youtube.com`, `mail.google.com`, `calendar.google.com`, `drive.google.com`, `docs.google.com`)
  ```
  이 사이트들에서 사용자가 누른 버튼이나 키가 어떤 동작인지(예: 굵게, 재생) 알아보고, 단축키가 있으면 화면 구석에 알림 카드를 보여 줍니다. 버튼 이름과 화면에 표시된 단축키만 읽고, 입력한 글자나 문서·메일·동영상 내용은 읽거나 저장하지 않습니다. 이 다섯 사이트 외에는 접근하지 않습니다.
  ```

**원격 코드 사용**: 아니요, 원격 코드를 사용하지 않습니다. (모든 코드는 패키지에 들어 있습니다.)

**데이터 사용** — 수집하는 데이터 유형에 체크:

- [x] **사용자 활동** (클릭·키 입력): 지원 사이트에서 누른 버튼이 단축키가 있는 동작인지, 그 동작을 마우스로 했는지 단축키로 했는지
- [x] **웹사이트 콘텐츠**: 동작 이름으로 쓰려고 화면에 표시된 버튼 이름(예: "굵게")을 저장
- [ ] 나머지(개인 식별 정보, 건강, 금융, 인증 정보, 개인 통신, 위치, 웹 기록)는 체크하지 않음

모두 이 기기에만 저장되고 전송되지 않지만, 스토어 정책은 기기 안에서만 처리하는 데이터도 공개하도록 요구합니다.

**인증 3개 모두 체크**: 승인된 용도 외 제3자 판매·전송 안 함 / 단일 목적과 무관한 용도로 사용·전송 안 함 / 신용도 판단·대출 목적으로 사용·전송 안 함
