유튜브에서 재생 버튼을 마우스로 누르면 K 키를, 구글 시트에서 셀을 마우스로 끌어 고르면 Shift+방향키를 알려 드려요. Gmail과 구글의 다른 업무 도구에서도 같은 방식으로 작동하고, 팝업에서 사이트마다 켜고 끌 수 있어요.

• 처음 알아본 동작에는 '손빠르미가 작동 중이에요' 카드를 한 번 보여 드려, 잘 켜졌는지 바로 아실 수 있어요.

• 최근 10번 중 8번 이상을 키보드로 하면 '익혔어요!' 카드를 보여 드리고, 그 뒤로는 알리지 않아요.

• 단축키 하나로 알림을 언제든 켜고 끌 수 있어요. 어떤 키인지는 팝업에 나와요.

■ 개인정보

## 개인정보 보호 관행 (Privacy practices)

**단일 목적**:

```
사용자가 유튜브, Gmail, 구글 캘린더·드라이브·문서·시트·슬라이드에서 마우스로 한 동작에 키보드 단축키가 있으면 그 단축키를 화면에 알려 주어, 일하면서 단축키를 익히도록 돕습니다.
```

**권한별 사용 이유**:

- `storage`
  ```
  알림 설정(알림 강도, 사이트별 켜고 끄기)과 단축키 학습 기록(동작 이름, 마우스/단축키 여부, 횟수, 날짜, 최근 동작 10개의 결과), 손빠르미가 알아보지 못한 버튼의 이름과 누른 횟수(많이 누른 50개)를 사용자 기기에 저장합니다. 설정만 크롬 동기화로 사용자의 다른 기기와 맞춰지며, 기록은 외부로 보내지 않습니다. 알아보지 못한 버튼 목록은 사용자가 '의견 보내기'에서 직접 넣기를 고를 때만 메일 본문에 들어갑니다.
  ```
- `scripting`
  ```
  설치하거나 업데이트한 직후, 이미 열려 있던 지원 사이트 탭에 확장 프로그램의 콘텐츠 스크립트를 넣어 새로고침하지 않아도 바로 작동하게 합니다. 패키지에 포함된 파일만 넣으며, 다른 사이트에는 넣지 않습니다.
  ```
- 호스트 권한 (`www.youtube.com`, `mail.google.com`, `calendar.google.com`, `drive.google.com`, `docs.google.com`)
  ```
  이 사이트들에서 사용자가 누른 버튼이나 키가 어떤 동작인지(예: 굵게, 재생) 알아보고, 단축키가 있으면 화면 구석에 알림 카드를 보여 줍니다. 버튼 이름과 화면에 표시된 단축키만 읽고, 입력한 글자나 문서·메일·동영상 내용은 읽거나 저장하지 않습니다. 이 다섯 사이트 외에는 접근하지 않습니다.
  ```

**원격 코드 사용**: 아니요, 원격 코드를 사용하지 않습니다. (모든 코드는 패키지에 들어 있습니다.)
