# 손빠르미 (Quickhand) 시험판 0.1.0

마우스로 한 동작에 단축키가 있으면 화면 오른쪽 아래에 알려 주는 크롬 확장 프로그램입니다.
이번 시험판은 **유튜브(일반 영상·쇼츠), Gmail, 구글 캘린더·드라이브·문서·시트·슬라이드**를 지원합니다.
Gmail의 한 글자 단축키(보관 E, 답장 R 등)는 Gmail **설정 → 바로가기 키 사용**을 켜야 작동합니다.

## 설치 방법

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `extension` 폴더를 선택합니다.
4. 첫 설치 안내 탭이 열리면 알림 강도를 고르고 **시작하기**를 누릅니다.
5. 툴바의 퍼즐 아이콘에서 손빠르미를 고정해 두면 팝업을 열기 편합니다.

설치하거나 새로고침(업데이트)하면 이미 열려 있던 지원 사이트 탭에도 자동으로 적용됩니다.
툴바 아이콘을 누르면 맨 위에 지금 탭에서 작동 중인지 나오고, 작동하지 않으면 **새로고침** 버튼이 함께 나옵니다.
유튜브에서는 감지에 쓰는 버튼(재생, 음소거, 영화관 모드 등)이 화면에 없으면 "일부 버튼을 찾지 못했어요"라고 알려 줍니다. 유튜브가 화면을 바꿨다는 신호입니다.

## 알림이 안 뜰 때

팝업의 **알림이 안 떴나요? 최근 동작 보기**를 열면 최근 동작 10개와, 각각 알림을 띄우거나 띄우지 않은 이유가 나옵니다.
예: "같은 동작 3번째부터 알려 드려요. (지금 2번째)", "알림 사이에는 1분을 두어요. 오후 8:48:44 이후에 다시 하시면 알려 드려요."
목록에 동작이 아예 없으면 그 버튼을 인식하지 못한 것이므로, 사이트 이름과 버튼 이름을 알려 주세요.

## 빠르게 시험해 보기

설치하자마자 작동하지만, 기본 강도(보통)는 같은 동작 3번째부터 알리고 알림 사이에 최소 1분 간격을 둡니다. 바로 확인하려면 이렇게 하세요.

1. **설정 → 알림 강도 → 적극적으로**를 고르면 첫 클릭부터 알려 줍니다.
2. 유튜브 영상에서 재생 버튼을 마우스로 누르면 `K` 안내가 뜹니다.
3. 구글 문서에서 툴바의 **굵게** 버튼을 누르면 `Ctrl + B` 안내가 뜹니다.
4. 그 뒤 키보드로 `Ctrl + B`를 여러 번 쓰면 '익혔어요!' 카드가 뜨고, 팝업의 **익힌 단축키**에 올라갑니다.
5. `Alt + Shift + P`(Mac은 `Option + Shift + P`)로 알림을 켜고 끌 수 있습니다.

## 알림 규칙 (기획서 기준)

| 강도 | 알림 시작 | 하루 새 단축키 | 같은 단축키 다시 알림 | 알림 사이 간격 |
| --- | --- | --- | --- | --- |
| 조금씩 | 같은 동작 5번째부터 | 2개 | 직전 알림부터 24시간에 1번 | 1분 |
| 보통 (기본) | 같은 동작 3번째부터 | 3개 | 1시간에 1번 | 1분 |
| 적극적으로 | 매번 | 제한 없음 | 매번 | 없음 (새 카드가 이전 카드를 바꿈) |

- 설치하자마자 작동합니다. 처음 알아본 마우스 동작이 아직 알릴 때가 아니면 "손빠르미가 작동 중이에요" 카드를 한 번만 띄웁니다(첫 동작부터 힌트가 뜨면 생략).
- 칭찬 효과(설정에서 끌 수 있음, 기본 켜짐): 알려 준 단축키를 키보드로 쓰면 "좋아요!" 카드에 익히기까지 남은 횟수를 점으로 보여 주고,
  마우스 없이 단축키를 5·10·20·30·50번(그 뒤 50번마다) 이어 쓰면 콤보 카드와 반짝이를 띄웁니다. 마우스로 단축키가 있는 동작을 하면 콤보는 0으로 돌아갑니다.
  칭찬 카드는 2초쯤 보이고, 다른 동작의 힌트 카드나 '익혔어요!' 카드를 가리지 않습니다. 애니메이션 줄이기 설정에서는 반짝이를 빼고 보여 줍니다.
- 알려 주기 전에 키보드로 쓴 단축키(아는 단축키)와 익힌 단축키는 최근 10번 중 키보드가 절반을 넘는 동안만 알리지 않습니다(`RULES.quietRatio`).
  마우스가 절반 이상이 되면 다시 알립니다. 아는 단축키는 새 단축키처럼, 익힌 단축키는 '익힘'을 풀고 "요즘 다시 마우스로 하고 계셨네요" 카드로 알립니다.
- 알림은 한 번에 하나입니다. 전체 화면 상태에서 누른 버튼에는 띄우지 않습니다. 전체 화면 버튼을 눌러 전체 화면이 될 때는 카드가 전체 화면 안에 보입니다.
  - 조금씩·보통에서는 처음 알려 주는 단축키가, 직전 알림이 이미 알려 준 단축키의 반복이었다면 1분을 기다리지 않습니다. 처음 알림끼리는 1분 간격을 지킵니다.
- 처음 알려 줄 단축키가 1분 간격 때문에 밀리면, 10분 동안은 이미 알려 준 단축키의 반복 알림보다 먼저 차례를 받습니다.
- 단축키를 키보드로 한 번이라도 누르면 팝업의 **익힌 단축키**에 들어갑니다(알림이 없었어도).
- 알림을 받은 단축키는 사용 기록이 10번 쌓인 뒤 최근 10번 중 80% 이상을 단축키로 하면 '익혔어요!' 카드를 띄우고 알리지 않습니다. 다시 마우스로 돌아가면(최근 10번 중 마우스 5번 이상) 익힘을 풀고 다시 알립니다. 이때도 강도별 반복 간격(보통 1시간)은 지킵니다. 다시 키보드로 익히면 '익혔어요!' 카드가 다시 뜹니다.
- 하루 새 단축키 상한과 오늘 횟수는 기기의 날짜가 바뀌면 초기화됩니다. 위의 반복 간격은 자정에 초기화되지 않습니다.
- 알림 카드의 **이 단축키는 그만 알리기**를 누르면 그 단축키는 더 알리지 않고, 오늘 놓친 단축키 목록에서도 빠집니다. 팝업의 **설정 → 알리지 않는 단축키**에서 **다시 알리기**로 되돌릴 수 있습니다.

## 기록과 개인정보

- 기록: 동작 이름, 마우스/단축키 여부, 횟수, 날짜, 최근 동작 10개의 시각과 결과 → `chrome.storage.local`(이 기기)
- 설정만 `chrome.storage.sync`(크롬 동기화)
- 입력한 글자, 문서·동영상 내용, 방문한 주소는 저장하지 않으며 외부로 보내지 않습니다.
- 이름이 등록된 단축키나 이 페이지의 버튼에서 확인한 단축키만 기록합니다. IME 조합 중 입력, AltGr 문자 입력, 입력란의 Mac Option 문자 입력은 제외합니다.
- 팝업의 **저장된 기록 보기**에서 확인하고 **기록 모두 지우기**로 삭제할 수 있습니다.
- 팝업의 **의견 보내기**는 의견 종류, 사이트 이름, 직접 적은 말, 버전 정보(손빠르미·크롬 버전, 운영체제, 화면 언어)와, 고른 경우 최근 동작 10개를 미리 보여 주고, 그 내용이 본문에 채워진 Gmail 편지쓰기(받는 사람 ehsheh@gmail.com)를 새 탭에 엽니다(클립보드에도 복사).
  확장 프로그램이 보내는 것은 없고, 사용자가 확인하고 보낼 때만 전달됩니다. 내용이 편지쓰기 주소에 실려 크롬 방문 기록에도 남습니다. 주소가 8,000자를 넘으면 최근 동작은 빼고 열고, 전체 내용은 복사해 둔 것을 붙여 넣게 합니다. (mailto 링크는 메일 앱이 정해지지 않은 크롬에서 주소만 보이는 빈 탭이 되어 쓰지 않음)

### 크롬 웹스토어 등록 (`../store`)

```bash
npm run pack                # ../dist/quickhand-<버전>.zip (업로드용, 실행에 필요한 파일만)
```

등록 화면에 붙여 넣을 설명·권한 사유·개인정보 답변은 `../store/listing.md`, 개인정보처리방침은 `../store/privacy-policy.md`,
스크린샷과 프로모션 타일은 `../store/`에 있습니다(다시 만들기: `checks` 폴더에서 `node store-shots.mjs`).
버전을 올릴 때는 `manifest.json`의 `version`을 바꾼 뒤 다시 `npm run pack` 하세요.

### 테스터에게 나눠 주기 (`../testers`)

```bash
npm run pack:testers        # ../dist/손빠르미-테스트판-<버전>.zip (설치 안내.html + "손빠르미" 폴더)
```

받은 사람은 압축을 풀고 `chrome://extensions` › 개발자 모드 › "압축해제된 확장 프로그램을 로드합니다"로 "손빠르미" 폴더를 고릅니다.
안내문 원본은 `../testers/설치 안내.html`(`{version}`은 버전, `{mascot}`은 캐릭터 그림으로 바뀜. 압축을 풀고 두 번 눌러 브라우저로 엶), 카톡으로 보낼 글은 `../testers/카톡 안내.txt`입니다.
처음 누를 때부터 익힐 때까지의 카드 10장 그림은 `checks` 폴더에서 `npm run storyboard`로 다시 만듭니다(`../dist/손빠르미-10단계.png`).

### 실제 사이트 점검 (`../checks`)

설치된 크롬을 점검용 프로필로 띄워 손빠르미를 불러오고, 실제 사이트에서 버튼을 눌러 카드가 화면에 보이는지 확인합니다.
점검용 프로필은 작업 폴더 밖 `%LOCALAPPDATA%\Quickhand\checks\.profile`에 있습니다(맥 등은 `~/.quickhand-checks/.profile`).
결과와 스크린샷은 `checks/results/`에 남습니다. 사이트 화면이 바뀐 것 같을 때 다시 돌려 보세요.

```bash
cd ../checks
npm install                 # 처음 한 번 (Playwright)
node youtube.mjs --headed   # 유튜브 일반 영상·쇼츠 (로그인 필요 없음)
npm run storyboard          # 새로 설치·보통 강도로 유튜브에서 카드 10단계를 찍어 한 장으로 (로그인 필요 없음)
npm run offline             # 외부 접속 없이 로컬 모형에서 실제 키·클릭·iframe 검사 (계정 불필요)
node reload.mjs             # 유튜브 탭을 연 채로 확장을 새로고침해도 카드와 그림이 오류 없이 뜨는지
node login.mjs              # 구글 로그인 창: 로그인한 뒤 창을 닫기
node google.mjs             # 문서·드라이브·Gmail·캘린더 (docs / drive / gmail / calendar 중 일부만 지정 가능)
npm run sheets-scenarios    # 시트 실사용 흐름 43가지(범위 끌기·Shift+클릭·머리글·구석 버튼·채우기 핸들·Shift/Ctrl+Shift+방향키·
                            # PageUp/Down·편집 중·머리글 뒤 서식 버튼)를
                            # 시험 문서에서 해 보고 기대와 맞는지 표로 (로그인 필요, results/sheets-scenarios.json)
npm run sheets-compat       # 시트 '호환되는 스프레드시트 단축키 사용'을 시험 문서에서 잠깐 켜고 엑셀식 키(Ctrl+2 등)를 세는지,
                            # 끄면 안 세는지 확인. 계정 전체 설정이라 끝나면(실패해도) 반드시 끔. 사용자에게 먼저 물을 것
npm run gmail-scenarios     # Gmail 목록에서 고르지 않고 E·#·Shift+U 등을 누르면 세지 않고, X로 고르거나 대화를 열면 세는지
                            # 시험 메일 한 통으로 13가지 확인 (로그인 필요, 끝나면 휴지통으로, results/gmail-scenarios.json)
node cleanup.mjs --keep-login  # 점검용 시험 문서를 모두 휴지통으로 (--keep-login 없으면 로그아웃까지 함)
```

`google.mjs`는 "손빠르미 점검용 (지워도 됨)" 문서를 새로 만들어 그 문서만 고치고, Gmail에서는 메일을 바꾸지 않는 버튼만 누릅니다.
캘린더에서는 이동·보기 전환·검색만 하고, 새 일정 창은 저장하지 않고 빠져나옵니다(끝에 이번 주 '제목 없음' 일정이 0개인지 확인).
로그인 창의 크롬은 창을 닫은 뒤에도 뒤에서 실행 중일 수 있습니다. 점검용 크롬이 열리지 않으면(종료 코드 21) 그 크롬을 먼저 닫으세요.
구글 로그인은 꼭 `node login.mjs` 창에서 하세요. 점검 스크립트가 띄운 크롬에서는 구글이 "로그인할 수 없음"으로 막습니다.
로그인 정보는 그 컴퓨터에 묶여 있어, 점검용 프로필을 다른 컴퓨터로 복사하면 다시 로그인해야 합니다.
로그인할 때 크롬 동기화는 켜지 마세요. 켜면 평소 쓰는 확장 프로그램이 점검 프로필에 깔려 점검에 끼어들 수 있습니다.
로그인 창에서 설정 › 시스템 › 온디바이스 AI도 꺼 두세요. 켜져 있으면 크롬이 점검 중에 기기 AI 모델(약 4GB)을 프로필에 받습니다.
점검이 끝나면 `node cleanup.mjs`로 점검용 문서를 휴지통으로 옮기고 로그아웃한 뒤, 점검용 프로필 폴더를 지우면 로그인 정보가 남지 않습니다.
계속 점검할 때는 `node cleanup.mjs --keep-login`으로 파일만 정리하고 로그인은 남겨 둘 수 있습니다.
