# 손빠르미 (Quickhand)

마우스로 한 동작에 단축키가 있으면 화면 오른쪽 아래에 살짝 알려 주는 크롬 확장 프로그램입니다.
일하면서 자연스럽게 손에 익히고, 익힌 단축키는 더 이상 알리지 않습니다.

예를 들어 유튜브에서 재생 버튼을 마우스로 누르면 `K`를, 구글 문서에서 **굵게** 버튼을 누르면 `Ctrl + B`를 알려 줍니다.

- **지원 사이트**: 유튜브(일반 영상·쇼츠), Gmail, 구글 캘린더·드라이브·문서·시트·슬라이드
- **현재 버전**: 0.1.6 (시험판)
- **권한**: `storage`, `scripting` — 입력한 글자, 문서·동영상 내용, 방문한 주소는 저장하지 않고 외부로도 보내지 않습니다

Gmail의 한 글자 단축키(보관 `E`, 답장 `R` 등) 안내를 받으려면 Gmail **설정 → 바로가기 키 사용**을 켜야 합니다.

## 설치 (개발자 모드)

빌드 과정이 없습니다. 내려받은 `extension` 폴더를 그대로 불러오면 됩니다.

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 저장소의 `extension` 폴더를 선택합니다.
4. 첫 설치 안내 탭에서 알림 강도를 고르고 **시작하기**를 누릅니다.
5. 툴바의 퍼즐 아이콘에서 손빠르미를 고정해 두면 팝업을 열기 편합니다.

사용법과 알림 규칙은 [extension/README.md](extension/README.md)에 자세히 적혀 있습니다.

## 폴더 구조

| 폴더 | 내용 |
| --- | --- |
| `extension/` | 확장 프로그램 본체 (manifest, 소스, 단위 테스트, 포장 도구) |
| `checks/` | 설치한 크롬으로 실제 사이트에서 알림 카드를 확인하는 Playwright 점검 스크립트 |
| `store/` | 크롬 웹스토어 등록 내용, 홍보 이미지, 스크린샷 |
| `testers/` | 테스터에게 보내는 설치 안내와 카톡 문구 |
| `mascot/` | 마스코트 이미지와 아이콘 원본 |
| `docs/` | 개인정보 처리방침, 기획 메모 |
| `이어하기.md` | 다른 컴퓨터에서 이어서 작업할 때 보는 진행 상황 정리 |

## 개발

Node 22 기준입니다. 확장 프로그램 자체에는 의존성이 없습니다.

```bash
cd extension
npm test              # 단위 테스트 (node --test)
npm run assets        # 아이콘·이미지 다시 만들기 (python)
npm run pack          # 웹스토어 업로드용 dist/quickhand-<버전>.zip
npm run pack:testers  # 테스터 배포용 ZIP
```

실제 사이트 점검은 `checks` 폴더에서 돌립니다.

```bash
cd checks
npm ci
npm run offline       # 로컬 fixture만 쓰는 오프라인 점검 (구글 계정·네트워크 불필요)
npm run youtube       # 실제 유튜브 점검
```

`main` 브랜치에 올리거나 PR을 열면 GitHub Actions가 단위 테스트, 오프라인 점검, ZIP 만들기를 자동으로 확인합니다.

## 기록과 개인정보

- 동작 이름, 마우스/단축키 여부, 횟수, 날짜는 `chrome.storage.local`(이 기기)에만 남습니다.
- 설정만 `chrome.storage.sync`(크롬 동기화)를 씁니다.
- 팝업의 **저장된 기록 보기**에서 확인하고 **기록 모두 지우기**로 지울 수 있습니다.

자세한 내용은 [docs/privacy.md](docs/privacy.md)를 보세요.
